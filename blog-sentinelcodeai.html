Building SentinelCodeAI: a PR review bot that runs entirely on your own machine

May 2026 · GitHub

Python · FastAPI · Ollama · GitHub App API · HMAC-SHA256

SentinelCodeAI is a GitHub App that reviews every pull request automatically, using a locally hosted LLM. No API key, no cloud, no cost per review. I built it because AI code review tools are usually a paid API call per PR, and I wanted to see if a local model could do the job well enough to be actually useful, not just a demo.

When a developer opens a PR, GitHub fires a webhook to a FastAPI server I wrote. The server verifies the HMAC-SHA256 signature on that webhook, fetches the diff, and sends it to qwen2.5-coder running through Ollama. The bot posts a structured review comment back on the PR automatically, covering bugs, security, performance, and general suggestions, plus a short summary.

Hardest part: GitHub App authentication. The app signs short-lived JWTs with an RSA key and exchanges them for installation-scoped tokens, and a silent 401 from a mismatched webhook secret took the most debugging to track down. Nothing about it fails loudly, it just quietly doesn't post a review, so I had to add real logging before I could see what was going wrong.

Most interesting part: how much prompt engineering actually changes the output. Adding a single line telling the model to never hallucinate issues that aren't in the diff, and forcing strict output sections, turned vague, generic-sounding reviews into ones that actually pointed at real lines and real problems. It's a good reminder that the model quality matters less than I expected and the prompt structure matters more.

Every webhook request gets verified with HMAC-SHA256 before anything runs, and the app's private key and secrets stay out of source control. Next on my list: inline comments on the specific changed lines instead of one summary comment, and severity scoring tied to GitHub status checks.

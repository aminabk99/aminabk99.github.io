Building a firewall simulator to understand how rule chains actually work

January 2026 · GitHub

Python · Network security

This is a Python simulation of how a network firewall monitors and filters incoming packets, enforcing whitelists, blacklists, signature detection, and DoS protection, with every decision logged to a timestamped file.

Every simulated packet, each carrying a source IP and payload, gets evaluated through a four-layer rule chain in order: a whitelist check that lets trusted IPs bypass everything else, a blacklist check that blocks known bad IPs immediately, signature detection that scans payloads for known malicious strings, and DoS protection that blocks and blacklists any IP that exceeds a packet threshold. Once an IP triggers a rule, it gets added to the blacklist for the rest of the session, so later packets from it are blocked instantly without re-scanning.

Hardest part: getting the rule chain order right. Whitelisted IPs have to bypass signature and DoS checks entirely, but blacklisted IPs need to be caught before signature scanning wastes any cycles on them. The ordering of that if/elif chain is the actual firewall logic, not just a formality.

Most interesting part: dynamic blacklisting mid-session. Once an IP trips a DoS or signature rule, it's blacklisted immediately and every subsequent packet from it gets blocked without re-evaluation, which is exactly how real firewall rule caches behave in production.

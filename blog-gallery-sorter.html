Building Gallery-Sorter: a TikTok-style swipe feed for cleaning up your phone's gallery

May 2026 · GitHub

Kotlin · MVVM · Jetpack · MediaStore API

Gallery-Sorter loads your photos and videos into a vertical swipe feed, newest first, and you swipe left to delete. The idea was to turn the tedious job of cleaning up a camera roll into something closer to the muscle memory people already have from swipe-based apps.

On launch the app requests photo and video permission, loads everything from device storage into a vertical ViewPager2 feed, and lets you swipe left on any item to delete it. On Android 11 and up, the system shows its own confirmation dialog before anything actually gets removed, and the names of deleted items are saved persistently so you can review them later from the profile screen. It's built with MVVM and Jetpack components: a ViewModel holding feed state, Coroutines for async work, and the MediaStore API for reading and writing device media.

Hardest part: getting swipe-to-delete right across Android versions. Android 11+ requires launching a system IntentSender for user confirmation, while older versions need a direct ContentResolver update instead, and both paths had to be handled cleanly so the UI never got left in a broken state if the user backed out of the confirmation.

Most interesting part: the feed itself. Using ViewPager2 in vertical orientation combined with ItemTouchHelper for the horizontal swipe gesture gives the app a genuinely satisfying TikTok-like feel, entirely with standard Android components and no third-party swipe libraries.

Classifying movie reviews without training a single model

April 2026 · GitHub

Python · NLTK · Lexicon-based sentiment analysis

This project classifies IMDb movie reviews as positive or negative using a weighted sentiment lexicon built directly from IMDb's own vocabulary files. No neural network, no training loop, just scored word matching. I wanted to see how far a genuinely simple, fully transparent method could get on a real sentiment task.

The pipeline has two stages. First, every review gets cleaned: HTML tags stripped, lowercased, punctuation removed, stopwords filtered, and Porter stemming applied, then saved to CSVs. Second, I load IMDb's vocabulary file paired with its per-word rating file to build a weighted lexicon, dropping any word with an absolute rating below 0.15 since those words carry too little signal to be worth keeping. Each review's words are summed against that lexicon, and a total below negative 0.5 gets classified negative, anything else positive. There's also an interactive mode where you can type any review and get an instant prediction.

It gets around 70% accuracy on the IMDb test set with zero model training.

Hardest part: calibrating the lexicon threshold by hand. Too low and too many neutral words drowned out the real signal, too high and there were too few words left to score anything meaningfully. The 0.15 cutoff and the negative 0.5 classification boundary were both tuned against the test set rather than picked from theory.

Most interesting part: getting solid accuracy without training anything. The entire classification decision is a sum of pre-rated word scores, which means the decision boundary is completely transparent, you can read exactly why a given review was classified the way it was. That's something no neural network can hand you for free.

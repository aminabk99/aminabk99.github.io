Using a power grid to practice C++ data structures, from raw pointers up

January 2026 · GitHub

C++ · OOP · Linked lists · Stacks

This is three small, independent C++ programs that all use a power grid as the domain, each one targeting a different data structures concept. powerplant.cpp defines a PowerPlant class and works through default and parameterized constructors plus dynamic memory with new and delete. powergrid_linked_list.cpp builds a singly linked list of plant nodes, traverses it to find the maximum capacity plant, and implements removal with proper cleanup. powergrid_event_stack.cpp implements a LIFO stack of timestamped grid events, faults, maintenance, startups, backed by a custom linked list instead of the standard library's stack.

Hardest part: manual memory management in the linked list. Every removal requires saving the head pointer, advancing head, then deleting the saved pointer in the right order, and getting that sequence wrong causes either a dangling pointer or a memory leak with no compile-time warning to catch it.

Most interesting part: building the stack from raw node pointers instead of using std::stack. It makes the LIFO behavior completely transparent, you can see exactly what push and pop do at the memory level, which is the whole point of doing it by hand once before reaching for the standard library version.

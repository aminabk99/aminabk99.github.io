Building a 4-bit CPU from individual logic gates up

December 2025 · GitHub

Digital logic simulator · Computer organization

This is a 4-bit R-Type CPU I designed and simulated in the Digital logic simulator, built from scratch starting at the gate level and working up through a full adder, an ALU, a register file, a program counter, instruction memory, and a 5-stage pipeline FSM into a complete functioning processor.

Everything is built hierarchically, each circuit is its own subcircuit that plugs into the next level up. A 1-bit full adder chains into a 4-bit adder, which feeds an ALU that multiplexes between add, subtract, and pass-through. Four general purpose registers built from D flip-flops form a register file with two simultaneous read ports. A 16-row instruction memory and a program counter with increment logic feed a 5-stage pipeline, fetch twice, decode, execute, write back, all driven by a single clock. I validated the whole thing with a test case that runs LDI, ADD, and SUB instructions through the full pipeline and checks the result.

Hardest part: wiring the instruction decode stage. Splitting the fetched instruction into opcode and register fields, routing those through multiplexers to control both the register file's write port and the ALU's operation select at the same time, and keeping all of it in sync with the 5-stage FSM clock took the most debugging of the whole project.

Most interesting part: watching a real program execute. Loading LDI R1, #5, then LDI R2, #3, then ADD R2, R1, and seeing the ALU output land on 8 at exactly the execute stage made the entire bottom-up build feel worth it. It's one thing to know a CPU works in theory, it's another to watch your own gates produce the right number.

🤖 AI Pipelines & Agents

AzureAutoFix

Agentic Azure AD error resolution system. A Chrome extension captures AADSTS error codes, a from-scratch PyTorch transformer classifies them against a custom AD error taxonomy (15 error codes), and the MS Graph API resolves admin-level issues automatically, usually in under 10 seconds. Two-tier security on write operations, so nothing gets fixed without someone actually authorized to fix it. Deployed on Railway via Docker.

Ask your Microsoft 365 governance a question and get the exact policy back, cited. Hybrid retrieval (dense vectors + BM25) fused with Reciprocal Rank Fusion, reranked by a cross-encoder, with an optional local-LLM summary and a calibrated confidence score. Runs fully offline. Formerly DocMind.

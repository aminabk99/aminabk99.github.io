🤖 AI Pipelines & Agents

AzureAutoFix

↗

Agentic Azure AD error resolution system. A Chrome extension captures AADSTS error codes, a from-scratch PyTorch transformer classifies them against a custom AD error taxonomy (15 error codes), and the MS Graph API resolves admin-level issues automatically — in under 10 seconds. Two-tier security on write operations. Deployed on Railway via Docker.

Agentic AI PyTorch FastAPI Azure AD MS Graph API Docker Railway

DocMind

↗

Fully local RAG document intelligence app. Upload PDFs, ask natural-language questions, and get cited answers with cosine-similarity confidence scores. LlamaIndex handles ingestion, ChromaDB stores vectors with Ollama nomic-embed-text embeddings, and llama3.2 generates answers — no API keys, no cloud cost. Containerized with Docker Compose.

RAG LlamaIndex ChromaDB Ollama FastAPI Docker

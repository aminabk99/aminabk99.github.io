A rule-based NLP chatbot, built to demonstrate the pipeline, not to be a product

January 2026 · GitHub

Python · Standard library only

This chatbot demonstrates the core stages of an NLP pipeline, tokenization, vocabulary filtering, unknown word handling, and rule-based response generation, using nothing but Python's standard library. No models, no APIs, no dependencies.

A message comes in, gets lowercased and stripped of punctuation, and each word is checked against a small defined vocabulary. Anything not recognized gets replaced with an [UNK] token. The known tokens are then mapped through a co-occurrence table to generate a response, and if nothing usable comes out of that, a fallback message is returned instead.

Hardest part: keeping it simple on purpose. It would have been easy to bolt on a real model or an API call, but the point was to show that a meaningful NLP pipeline, tokenize, filter, map, respond, works even at a tiny scale, without hiding the mechanics behind a library.

Most interesting part: the [UNK] token pattern. It's the same idea real neural NLP systems use to handle out-of-vocabulary words, and this project shows that concept working in about 60 lines of plain Python. Sometimes the smallest version of an idea teaches it better than the production one does.

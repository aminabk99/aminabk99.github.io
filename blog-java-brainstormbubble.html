Building a real-time collaborative brainstorming tool from a raw TCP socket up

December 2025 · GitHub

Java · JavaFX · TCP sockets · JSON

BrainStorm Bubble is a Java desktop app that lets multiple people create, drag, and connect idea bubbles on a shared canvas in real time, built on a custom TCP client-server architecture with a JavaFX GUI on each end.

The server listens on port 8080 and keeps a live canvas state with every bubble and connection. Each client connects over a TCP socket, receives the current canvas state the moment it joins, and renders it in its own JavaFX window. When someone creates, moves, or deletes a bubble, their client sends a JSON message to the server, the server updates its state and broadcasts the change to every other connected client, and everyone's canvas stays in sync.

Hardest part: keeping every client in sync without conflicts. When two people drag bubbles at nearly the same moment, both send updates to the server almost simultaneously, and making sure the server processed them in order and broadcast the correct final state to everyone required careful use of a thread-safe list and synchronized methods on the shared canvas state.

Most interesting part: the initial state sync. When a new client connects mid-session, the server immediately sends the full current canvas as one message so the new client sees exactly what everyone else already sees. Building that catch-up mechanism from scratch, with no framework doing it for me, is what actually made the multiplayer feel seamless instead of janky.
